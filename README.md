## Interaction

- Hover the coral domino for a small, responsive tilt.
- Tap it, drag it toward the chain, flick it, or use the visible keyboard-accessible push button.
- The domino is the CTA. Its first activation immediately unlocks the page and automatically hands off to selected work. There is no second continuation click and navigation does not wait for the cascade.
- Before activation, later chapters are hidden and inert. They have no ScrollTriggers and scrolling cannot start them.
- After activation, the connecting thread carries the story into Superforms. Tap the Three.js cover or use Open Superforms; paper tabs and HTML controls open the brief, interface, and response. The printed faces follow the live portfolio demo.
- In the form study, choose a brief, edit a question, change its required rule, and test an answer. Editor, preview, and validation share one local question object. An unsafe-edit experiment protects its identity. The implementation note can be read and downloaded.
- Choose an intention in the portfolio interaction study. Product, Frontend, or Distribution changes the collection's framing, closing invitation, evidence link, and email subject. These choices never block reading.
- The ornamental tilted-paper handoff has been removed. The next section contains Project brief, Interaction study, and Live destination documents. Wide, tall desktop viewports keep the reader sticky while scroll progress opens successive documents. Manual controls work everywhere; reduced motion and smaller viewports use the direct reader.
- Mechanism studies include voice-session connection/recovery, shared comparison criteria, a deterministic network, an example chip settlement, a debugging evidence trail, and an institutional entry. Luman opens its Godmode study. These are explicitly described demonstrations, not production services or screenshots.
- Start again or the footer replay control returns to the opener, re-locks the rest of the journey, and requires a fresh interaction.
- Optional synthesized sound is off by default.

- The Luman diagram is a labeled workflow study, not an invented screenshot. Its dashboard/Godmode toggle and tool explanations work.

## Architecture and performance

- React for content and discrete interface state.
- Lazy-loaded Three.js for a manually composed scene. Rounded geometry, ceramic materials, canvas-drawn domino faces, studio environment, and soft shadows. No external 3D models, generated images, or stock UI components.
- GSAP owns event choreography and ScrollTrigger owns section reveals. No React state updates in the render loop.
- Demand rendering: idle scenes do not request frames. Resize, gestures, and finite transitions request rendering.
- The Superforms folio imports only when its unlocked chapter approaches the viewport. It shares the lazy Three.js chunk and uses four paper solids with manually printed canvas textures. No physics, postprocessing, or live shadow maps.
- One coalesced render queue services gestures, tweens, resize and the cascade. Offscreen/hidden scenes pause both rendering and the simulation clock.
- Pixel ratio capped at 1.25 on narrow screens and 1.5 otherwise. Shadow maps use 1024 resolution and update only when the scene changes.
- Pointer hover hit testing is coalesced to one update per frame. Dragging cancels hover tweens; vertical touch intent does not push the first piece.
- The connecting thread is a single responsive SVG path, measured on layout changes. Cached cubic samples map reading height to path length without layout or SVG geometry reads during scrolling. Replay removes it; the direct reading route does not activate it.
- Wheel, touch scrolling and navigation cancel the automatic handoff, including its initial wait. Cancellation preserves the visitor's scroll position.
- Geometry and materials are reused; per-instance face maps and GPU resources are disposed on teardown.
- Local Latin-only Manrope variable font. WebGL failure, context loss, and import failure have a functional SVG alternative.
- Reduced motion replaces the cascade and auto-scroll with immediate state changes and removes scroll reveals. Preference changes are observed live. Touch keeps vertical page scrolling, and the initial handoff yields to manual scrolling.

The domino cascade is a deterministic hinged animation with an accelerated fall and contact rebound, not a rigid-body simulation. Fixed composition makes the result reproducible and avoids a physics-engine download. Pieces settle at an overlapping resting angle.
